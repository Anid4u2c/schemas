# Shared schemas

Reusable schemas are grouped by format:

- `json/` contains JSON Schema documents.

Consumers should reference the stable raw GitHub URL for a document under
`json/`, for example:

`https://raw.githubusercontent.com/Anid4u2c/schemas/main/json/project.schema.json`

The schemas use JSON Schema draft 2020-12.  Related schema references are
relative paths so that the set can be versioned or hosted together.
